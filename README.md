# Davilanco Shop

A static-first, multi-role commerce storefront built with HTML, CSS, vanilla JavaScript, Cloudflare Pages Functions and D1.

## Setup

See [DEPLOYMENT.md](DEPLOYMENT.md) for Cloudflare setup, D1 migrations, and secret configuration.

## Important

Payment and supplier integrations require credentials and provider-side configuration. Never put secrets in frontend code. AliExpress ordering is intentionally gated behind admin approval.
